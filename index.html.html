Cấu trúc câu quan trọng — 重要句型
① Hỏi tên — 问名字
你叫什么名字？/ 你贵姓？
Bạn tên gì? / Quý danh của bạn là gì?
→ 我叫玉碧。/ 我姓阮。
② Hỏi tuổi — 问年龄
你多大？/ 你今年多大？/ 你几岁？
Bạn bao nhiêu tuổi? (thông dụng / trẻ em)
→ 我二十八岁。/ 我今年三十一岁。
③ Hỏi địa điểm — 问地点
你在哪里？/ 你去哪里？
Bạn ở đâu? / Bạn đi đâu?
→ 我在仓库。/ 我去上班。
④ Hỏi giờ — 问时间
现在几点了？/ 你几点上班？
Bây giờ mấy giờ? / Bạn mấy giờ đi làm?
→ 现在八点半。/ 我七点上班。
⑤ Phủ định — 否定句 · 不 vs 没有
不 (bù) + ĐT · 没有 (méiyǒu) + ĐT
不 = phủ định hiện tại/tương lai · 没有 = phủ định quá khứ
→ 我不去。/ 昨天我没有加班。
⑥ Hỏi công việc — 问工作
你做什么工作？/ 你负责什么？
Bạn làm công việc gì? / Bạn phụ trách gì?
→ 我做主管。/ 我负责仓库和包装部门。
